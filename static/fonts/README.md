# Arabic PDF font

ضع هنا واحدًا من الملفين التاليين قبل استخدام تصدير PDF:

- `NotoSansArabic-Regular.ttf` من مشروع Google Noto (ترخيص SIL Open Font License).
- `DejaVuSans.ttf` من مشروع DejaVu Fonts (ترخيصه المرفق بالمشروع).

لا تغيّر اسم الملف. لا يعتمد التطبيق على مسارات خطوط خاصة بنظام التشغيل.
